# Crystal Pure — recreated website

This is a self-contained recreation of the publicly deployed Crystal Pure website at:
https://temp-vercel-dep.vercel.app/#water

## Run locally
Open `index.html` directly in a browser, or use any simple static server.

## Notes
- Brand/title preserved: **Crystal Pure — Pure RO · Pure Life**
- The `#water` section is included and works as a direct anchor.
- Responsive layout for desktop and mobile.
- No backend or build step is required.
- Replace the CSS-drawn bottle/graphics with original brand assets if you have them.
